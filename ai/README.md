# Bio-Firewall AI

Expected classification states:

1. Normal
2. Physiological Change
3. Cyber-Tampered

The presentation describes cross-vital behavioral analysis using Heart Rate, SpO2 and Temperature. The production ML model can be placed here and exported to TensorFlow Lite / Lite Micro for edge deployment.

The React dashboard currently includes a safe demonstration simulator so the presentation can be shown even before the physical ESP32 is connected.
